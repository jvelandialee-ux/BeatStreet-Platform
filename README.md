# BeatStreet Platform

Landing page de plataforma dedicada a los videojuegos y a la cultura HipHop, desarrollada con React y BootStrap

 ## Descripcion

Cada persona interesada en la cultura encontrara videojuegos basados en los 4 fundamentos de la culturas, podra conocer novedades y explorar categorias

## Tecnologias 

- React 19
- BootStrap 
- Node.js y npm

## Requisitos

-Node.js
-npm ( instalado con Node.js)

## Cómo ejecutar el proyecto

1. Clona el repositorio:
   ```bash
   git clone https://github.com/jvelandialee-ux/BeatStreet-Platform.git
   ```
2. Entra a la carpeta del proyecto:
   ```bash
   cd mi-pagina
   ```
3. Instala las dependencias:
   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
5. Abre en el navegador la dirección que aparece en la terminal (normalmente http://localhost:5173).

## Otros comandos

- `npm run build`: genera la versión de producción en `dist/`.
- `npm run preview`: muestra localmente esa versión.
